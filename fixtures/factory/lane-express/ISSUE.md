# docs(notes): date the next release in the calendar

## Why

The calendar note has no date for the next release.

## What to build

Add the date to `docs/notes/calendar.md`.

## Requirements

Plain text, one sentence.

## Acceptance criteria

- [ ] `docs/notes/calendar.md` names the date of the next release.
- [ ] `npm test` passes.
- [ ] Verified by the maintainer by reading the diff.

## Out of scope

Anything but `docs/notes/calendar.md`.

## Delivery

The agent prepares the change; the maintainer reads it.
